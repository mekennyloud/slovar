# Словарь

Англо-русский словарь для iPhone. Одна функция — поиск. Работает без интернета: после первого открытия весь словарь (около 3 МБ по сети, 9 МБ на устройстве) лежит в телефоне.

## Что умеет поиск

- Английское слово — список слов, начинающихся так же, точное совпадение первым. Enter открывает первое.
- Форма слова (stopped, cities, going) — подсказывает начальную форму.
- Опечатка (watre) — предлагает похожие слова.
- Русское слово — ищет по переводам (собака → dog, hound, …).
- Избранное: звёздочка справа от слова в статье, список — кнопка со звездой в шапке. Хранится только на этом телефоне (localStorage, ключ `slovar:fav`).
- В статье: нажатие на помету (_разг._, _ам._) показывает расшифровку, ссылки «см.», «от go» открывают нужную статью.

## Откуда словарь

В. К. Мюллер, «Англо-русский словарь», 7-е издание (1961), около 46 тысяч статей. Электронная версия С. Старостина и Е. Цымбалюка, лицензия GPL-2.0+. Взят из пакетов Debian `mueller7-dict` и `mueller7accent-dict`; из второго берутся ударения.

## Как устроено

- `index.html`, `style.css`, `app.js` — всё приложение, без сборки.
- `ds/` — дизайн-система «Каракули»: токены, компоненты, котики, витрина `ds/index.html`. Правила — `ds/README.md`.
- `fonts/` — Pangolin и Balsamiq Sans (OFL), лежат локально ради работы без сети.
- `data/mueller.json` — словарь: `h` — слова, `b` — статьи, `abbr` — расшифровки помет.
- `tools/build_dict.py` — пересобрать `data/mueller.json` (сам скачает пакеты Debian).
- `sw.js` — кэш для работы без интернета. Поменяла файлы приложения — подними `APP`, пересобрала словарь — `DATA`.
- `design/icon.svg` — исходник иконки.

## Команды

- Посмотреть на Mac: `python3 -m http.server 8771` в папке → http://localhost:8771 (на localhost кэш выключен, правки видны сразу)
- Опубликовать: `zsh tools/publish.sh` → https://mekennyloud.github.io/slovar/
- На iPhone: открыть адрес в Safari → «Поделиться» → «На экран „Домой“».
