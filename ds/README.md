# Каракули — дизайн-система Словаря

Рисунок тушью на белой бумаге, как в инди-играх про котиков. Витрина со всеми частями: `ds/index.html` (на Mac: http://localhost:8771/ds/).

## Правила

1. Белая бумага, чёрная тушь. Всё, что можно нажать, обведено линией от руки.
2. Без теней и градиентов. Глубина только от серых плашек и затемнения.
3. Цвета мало. Жёлтый — одно главное действие или найденное. Голубой — процесс. Рыжий и серый — котики.
4. Pangolin (рукописный) — слова, заголовки, кнопки. Balsamiq Sans (эскизный) — длинный текст.
5. У каждой рамки углы разные (`--r-sketch`), чтобы она выглядела нарисованной.
6. Котики живут в пустых местах: пустой поиск, «не нашлось», загрузка, подсказки.
7. Ночью бумага — грифельная доска, тушь — мел. Жёлтый и мордочки котиков остаются тёмными внутри.

## Файлы

- `tokens.css` — цвета, шрифты, линии, углы, отступы. Тёмная тема — там же.
- `components.css` — классы с приставкой `k-`.
- `doodles.js` — рисунки: `DOODLES.loaf`, `sit`, `lie`, `face`, `paw`, `star`, `loupe`, `back`, `close`.
- `../fonts/` — шрифты лежат в приложении, чтобы всё работало без сети. Лицензия OFL, тексты рядом.

## Компоненты

| Класс | Что это |
|---|---|
| `k-btn`, `--primary`, `--quiet` | кнопка; жёлтая — главная, серая — тихая |
| `k-round` + `k-round__face` | круглая кнопка с подписью снизу, `--sm`, `--primary` |
| `k-field` + `__icon`, `__input`, `__clear` | поле поиска |
| `k-card`, `--gray` | карточка в рамке или серая плашка |
| `k-window` + `__bar`, `__body`, `--app` | окно с тёмной шапкой или с тремя точками |
| `k-chip`, `--line` | помета (разг., ам.) |
| `k-tag`, `--fill` | квадратик с номером или омонимом |
| `k-bubble`, `--white` | пузырь «…» |
| `k-say` + `__who`, `__text` | реплика котика в двойной рамке |
| `k-progress`, `--run` | синие кирпичики загрузки |
| `k-meter` | полоска-шкала |
| `k-star` + `aria-pressed` | звёздочка «в избранное»; нажатая — жёлтая, `k-pop` — подпрыгнуть |
| `k-row`, `k-list` | строка списка |
| `k-rule` | волнистая черта |
| `k-toast` | всплывает снизу |
| `k-mark` | маркер для найденного |
| `k-st` | ударение штрихом над гласной (знак U+0301 в Balsamiq съезжает) |

## Нельзя

- Ровные прямоугольники с одинаковыми углами и тени.
- Больше одного жёлтого на экране.
- Рукописный шрифт для длинных абзацев.
- Цветной текст. Цвет только у заливок.
